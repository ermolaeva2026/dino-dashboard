# Автообновление дашбордов PRK-2026-DS

Источник статусов реализации: `PRK-2026-DS_KSG_DinoPark.mpp`.

Источник фото: `Фотофиксация работ`.

Источник сметы и документов: корень проекта `ДиноПарк. Модернизация`.

Все листовые задачи КСГ включаются в основной дашборд независимо от уровня вложенности и от того, раскрыта ли структура в окне MS Project. Сводные строки третьего уровня используются как подблоки, а вложенные работы показываются внутри соответствующей фазы.

Источник рисков: последняя версия `Документы PMO\PMO-02_07_Reestr_riskov_PRK-2026-DS*.xlsx`. Формальный статус берется из колонки `N`, комментарий по риску — из колонки `P`. Если комментарий сообщает, что риск не реализовался, а формальный статус остается активным, дашборд сохраняет риск активным и отмечает необходимость финализации статуса.

Источник финансовых показателей: только первая вкладка `Смета расходов Зерно` файла `Смета_Динопарк_PRK-2026-DS.xlsx`:

- подтвержденные затраты и бюджеты фаз — колонка `D`, итоговые строки 7, 12, 16, 21 и 22;
- фактические платежи — колонка `E`, итоговая строка 22;
- неоплаченные обязательства — `F22`;
- план, утвержденный бюджет, резерв и остатки — строки 25–30.

Нижний контрольный блок строк 38–47 не используется генератором: он содержит вспомогательные формулы и может быть временно не рассчитан после перестройки вкладок.

Запуск вручную:

```powershell
powershell -ExecutionPolicy Bypass -File "Автообновление дашбордов\update-dashboards.ps1"
```

Или двойной клик по `update-dashboards.cmd`.

Для ручного запуска канонической пересборки можно использовать:

```cmd
rebuild-canonical-dashboards-scheduled.cmd
```

Фактически wrapper запускает:

```powershell
rebuild-canonical-dashboards-scheduled.ps1
```

Логи пишутся в `Автообновление дашбордов\logs`.

`update-dashboards-scheduled.cmd` оставлен как технический wrapper для локальной пересборки без публикации и не используется в активном расписании.

Что обновляется:

- `PRK-2026-DS_Рабочий_дашборд.html` — даты, проценты, статусы задач, блок "требуют актуализации", документы.
- `PRK-2026-DS_Dashboard.html` — фазы из КСГ и фотогалерея из папок фотофиксации.
- `PRK-2026-DS_dashboard-data.json` — машинный снимок данных для проверки.

Активное автоматическое расписание держится на двух последовательных задачах Windows Task Scheduler в папке `\Skazka PMO\`:

- `PRK-2026-DS GitHub Publish 09` — ежедневно в `09:00`.
- `PRK-2026-DS GitHub Publish 18` — ежедневно в `18:00`.

Каждая задача через `publish-to-github-scheduled.cmd` сначала обновляет оба дашборда из КСГ, затем синхронизирует CEO-дашборд и только после этого публикует единый комплект на GitHub Pages. Параллельный запуск нескольких сборщиков запрещен: MS Project COM возвращает `0x80080005` при конкурирующем доступе к одной `.mpp`.

Отключены как старые или конфликтующие:

```cmd
PRK-2026-DS Dashboards 09
PRK-2026-DS Dashboards 18
PMO - ДиноПарк дашборд (PRK-2026-DS)
PMO - ДиноПарк РАБОЧИЙ дашборд (PRK-2026-DS)
ДиноПарк — публикация на GitHub Pages
```
